# Flipper Fapper 🐬

> *"Go up. Go down. Control the speed."*

A joke app for the Flipper Zero. Born from a Reddit comment about FlipperFAP.

## Controls

| Button | Action |
|--------|--------|
| ◀ Left | Decrease speed |
| ▶ Right | Increase speed |
| ✓ OK | Toggle vibration on/off |
| ↩ Back | Exit |

## Speed Levels

| Level | Label | Delay |
|-------|-------|-------|
| 1 | SLOW | 1200ms |
| 2 | EASY | 800ms |
| 3 | MED | 500ms |
| 4 | FAST | 300ms |
| 5 | MAX | 150ms |

## Building

Drop this folder into your Flipper Zero firmware's `applications_user/` directory and build with:

```bash
./fbt fap_flipper_fapper
```

Or submit the repo to [FlipperFAP](https://flipperfap.com) and let it build for you. 😏

## Why does this exist?

Someone on Reddit thought FlipperFAP was an adult site. They were wrong. This app is our formal apology.
